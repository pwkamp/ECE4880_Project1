# FW-04 — LCD, Buttons, and Backlight

Connect the ESP32 micro-USB/UART cable, close ESP-IDF Monitor, and leave the box continuously ON; this section does not include a restart or power-off check. With serial event markers active, exercise each sensor button independently in connected and disconnected states. Verify numeric, OFF, DISCONNECTED, signed-temperature, and average rendering rules. Exercise every selected backlight level and confirm indoor readability. Measure valid button-event-to-LCD-render software contribution; the intended scheduling contribution must not exceed approximately 20 ms. Operator visual confirmation is mandatory.
