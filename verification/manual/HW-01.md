# HW-01 — Physical Configuration and Design Inspection

Human evidence is mandatory. Measure both sensor cables (pass: 0.9–1.1 m); inspect strain relief, permanent port identification, connector support/protection, battery/regulator/switch, ESP32/BLE capability, sensor range/accuracy datasheets, LCD character capacity/readability, signed values, and usable backlight levels. Record model/part numbers, numerical measurements, datasheet revisions, and photo paths. This inspection supports design/construction claims but does not replace HW-02 drop testing or HW-04 accuracy testing.
