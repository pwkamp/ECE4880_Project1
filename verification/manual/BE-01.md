# BE-01 — Worker Isolation, 1-Hz Polling, and Persistence

The runner first executes the deterministic backend worker tests. It then confirms the real third box is connected, captures a baseline, prompts the operator to disconnect and reconnect each sensor in turn, and records backend status plus MySQL-backed `/api/samples` data throughout. Pass/fail is computed from fault visibility, continued valid samples from the unaffected sensor, persistence, and automatic recovery. The operator only performs the physical cable actions.
