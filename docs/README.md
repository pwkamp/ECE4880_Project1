# Thermometer design documentation

subsystem: the qualification report and the screenshots used in the root
README.

- [`qualification-report.pdf`](qualification-report.pdf) is the requirements
  qualification report generated by [`verification/`](../verification/).
- [`screenshots/`](screenshots/) holds the images referenced from the root
  [`README.md`](../README.md).

[`firmware/README.md`](../firmware/README.md),
